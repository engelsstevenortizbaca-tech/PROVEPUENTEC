# Server — Backend (Node.js + Express)

API REST del Marketplace construida con **Node.js** y **Express**.

## Estructura

```
src/
├── config/       # Configuración (conexión a BD, variables de entorno)
├── controllers/  # Lógica de manejo de peticiones/respuestas
├── routes/       # Definición de endpoints
├── models/       # Modelos y acceso a datos
├── middlewares/  # Middlewares (autenticación, errores, validación)
├── services/     # Lógica de negocio
└── utils/        # Funciones utilitarias
```

> Fase inicial: aún no se han instalado dependencias ni implementado funcionalidades.
